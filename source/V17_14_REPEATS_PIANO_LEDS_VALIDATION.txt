Change 1 - PIANO mode key LEDs
- While Mode = PIANO, all 27 hardware piano-key LEDs are forced bright/on.
- This overrides the normal scale-key LED preference only while PIANO mode is selected.
- Leaving PIANO restores the existing scale-light behavior.

Change 2 - Rings Delay Repeats
- Rings DELAY page now uses all four knobs:
    K1 Time      20..1500 ms
    K2 Feedback  0..85%
    K3 Mix       0..100%
    K4 Repeats   Inf, 1..8
- Repeats = Inf preserves the v17.13 feedback-only behavior.
- Finite values count the overall Rings delay stream. Repeat #1 comes from the original delay contents;
  feedback is allowed only long enough to create the requested additional repeats.
- A new Rings strike restarts the overall repeat count. It does not allocate per-note delay buffers.
- No additional delay buffer is used, so the CPU/RAM impact is negligible.

Focused audio validation (same Time/Feedback/Mix and one manual Rings strike):
