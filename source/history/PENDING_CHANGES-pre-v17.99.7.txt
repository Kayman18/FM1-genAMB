1. RINGS: KEEP MODAL, SYMPATHETIC AND STRING
The latest instruction supersedes the earlier proposal to remove only Rings FM.
Remove the selectable FM, Sym Q, Str+Rev and StrSynth models and their unused
DSP state. Modal, Sympathetic and String retain their existing sound and 1..4
polyphony. Model modulation spans the three retained choices and preserves
hysteresis, next-strike switching and the existing transition fade.

The internal FM array, internal Rings reverb, StringSynthPart, shared 65,536-byte
effects buffer, quantized sympathetic chord table and String FX selector state
are removed from the compiled implementation. The standalone Zen FM synth,
all 16 FM presets, global Clouds reverb and sends, and Rings mini delay remain.
Unused upstream vendor sources are retained as provenance but are not compiled.

The obsolete String FX control is removed from the Rings Exciter page:
Damping / Position / blank / Exciter. Its saved parameter slot remains inert.

Old valid project model IDs map on load, including all eight saved pieces:
  0 Modal        -> Modal
  1 Sympathetic  -> Sympathetic
  2 String       -> String
  3 FM           -> String
  4 Sym Q        -> Sympathetic
  5 Str+Rev      -> String
  6 StrSynth     -> String
Remaining settings are preserved. Removed models naturally no longer produce
their former sound. Invalid stored IDs are rejected before any fallback mapping.

2. STANDALONE FM: SIX AVAILABLE VOICES
The Voices selector now permits 1..6. Default and existing saved four-voice
settings remain four; select five or six when wanted. MIDI-out gate tracking
has the same six-slot capacity. Core arithmetic, the 16 presets, per-voice gain,
allocation policy, release behavior and C2 worker safeguards remain intact.

FM pool state grows 1,632 -> 2,256 bytes (+624); MIDI gates add 16 normal-RAM
bytes. The explicit local FM allowance is 2,408 bytes, leaving 152 bytes there.
More pool RAM is available, but raising polyphony beyond six is not part of this
approval. Six active voices can require about 50% more FM operator work than
four; that is not a prediction of whole-device CPU percentage. Next-build/device
checks must confirm timing and final mixed-output headroom at six voices.

3. SHARED DISPLAY CANVAS
Reduce the shared RGB565 canvas from 240x144 to 240x132, saving 5,760 pool bytes.
The largest production draw band is 132 rows. Mixer uses two 102-row bands;
other pages, help, splash and boot/update text fit. Layout, drawing dimensions,
clipping bounds, DMA lengths, synchronization and redraw order stay unchanged.

4. OCTAVES
PAD1, PAD2, Rings and FM choices: -4, -3, -2, -1, 0, +1, +2.
The upper limit stays +2; recipe/default values retain their previous behavior.
Sequence-page knobs, OCT-/OCT+ buttons and main-page cards share these values.
Original Rings/FM -3/-4 play one/two octaves below the former -2 result while
all old -2..+2 mappings remain unchanged. Pad audio/MIDI/display use consistent
pitch-class-preserving bounds when -4 plus downward Oct Drift would go below
MIDI0. Manually transposed Rings pitches are bounded before byte packing.
